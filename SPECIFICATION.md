# О проекте
Этот проект - сервис-аналог cal.com с урезанным функционалом.

Для реализации фронтенда проекта будут использованы Vue 3, Vue Router и TypeScript. Для UI элементов будем использовать Element Plus (https://element-plus.org)
Для бэкенда будем использовать Ruby on Rails (API + общение с базой данных).

Итоговый результат - Docker-образ, который будет запускаться в контейнере.

## Описание функциональных требований проекта
"Запись на звонок" - урощённый сервис бронирования вермени по мотивам Cal.com.
Владелей публикует доступное время для встреч,а другой пользователь выбирает свободный слот и записывается на звонок.
Время для встреч представлено интервалами по 15 или 30 минут.

В проекте нет авторизации, личных кабинетов и ингераций с внешними календарям.

Владелец календаря в прилложении один и заранее известен.
Владелец заводит типы встреч,у каждого есть название, описание и длительность.
Владелец может видеть список предстоящих встреч всех типов.

Гость заходит без регистрации, выбирает тип встречи, открывает календарь на ближайшие 14 дней и записывается на свободный слот.
Слот длится столько, сколько выбранный тип встречи.
Одно и то же время нельзя занять дважды, даже разными типами встреч.

Обязательная часть работы с API состоит из TypeSpec-контракта, сгенерированной OpenAPI-спецификации и клиентского SDK для фронтенда.
Нужно проверить,что для языка фронтенда есть генератор клиента из OpenAPI.
Серверные типы и маршруты генерируются, если выбранный фреймворк это поддерживает.
При отсутствии серверного генератора бекенд реализуется по контракту и проверяется тестами.

Окно записи занимает 14 календарных дней и сдвигается с течением времени.
Начало с сегодняшнего или завтрашнего дня, часы работы владельца и часовой пояс выбирается и записывается в спецификации.
Длительность слота совпадает с длительностью типа встречи, шаг доступных стартов тоже фиксируется с спецификации.
Пересечение интервалов запрещено, включая частичное наложение разных типов.
Следующая встреча может начаться в момент завершения предыдущей.
Правила действуют и для двух запросов, пришедших одновременно.

Данные можно хранить в памяти процесса. В этом случае перезапуск сбрасывает записи, и это ограничение нужно назвать в README.md.
База с сохранением данных тоже допустима.

## Описание визуальной части интерефейса

1. Главная страница
1.1. На главной странице есть "шапка" сайта с названием проекта "Calendar", а также ссылками "Записаться" и "Админка"
1.2. На основной части страницы указана надпись "Быстрая запись на звонок", Название, текст "Забронируйте встречу за минуту, выберите тип события и удобное время", а также кнопка "Записаться ->"
1.3. На основной части страницы присутствует описание "Возможности" со списком ключевых функциональных возможностей проекта: "выбор типа события и удобного времени", "быстрое бронирование", "управление типами встреч".

2. Страница записи
2.1. В шапке сайта выделена текущая страница "Записаться"
2.2. На основной части сайта есть надпись "Выберите тип события" и подпись "Нажмите на карточку, чтобы открыть календарь и выбрать удобный слот."
2.3. Две карточки:
    - "Встреча 15 минут" (название) и подпись "Короткий тип события для быстрого слота."
    - "Встреча 30 минут" (название) и подпись "Базовый тип события для бронирования."
2.4. На каждой карточке должен быть label/badge с соответсющей надписью длительности "15 мин" или "30 мин"

3. Страница записи
3.1. В шапке так же подсвечивается ссылка "Записаться"
3.2. Отображается заголовок h1 с текстом-названием типа встречи
3.3. Отображается три столбца:
    3.3.1. Левый (сверху вниз):
        - Данные пользователя (пока это просто "Василий Петров" и надпись "Host")
        - Название встречи (пример: "Встреча 15 минут" и label/badge "15 мин")
        - Описание (пример: "Короткий тип события для быстрого слота.")
        - Вложенная карточка "Выбранная дата" с текстом "Дата не выбрана" когда пользователь ещё не выбрал дату, и с датой, когда пользователь выбрал дату.
        - Валоженная карточка "Выбранное время". Аналогично дате - "Выбранное время" и "Время не выбрано"
    3.3.2. Средний столбец (сверху вниз):
        - Надпись "Календарь" и стрелки переключения месяца: предыдущий "<-", следующий "->"
        - Выбранные месяц и год: март 2026 г.
        - Календарь с видом дней недели: Пн, Вт, Ср, Чт, Пт, Сб, Вс. Дни представлены числами/датами и выглядят как квадрат. Если день с другого месяца (например,неделя заканчивается в понедельник и мы показываем дни до конца недели) - квадраты должны визуально отличаться от текущего месяца.
        - Каждая дата-квадрат кликабельны и выбирают определенную дату
    3.3.3. Правый столбец (сверху вниз):
        - Заголовок "Статус слотов"
        - Выбор слотов списком:
            - 09:00 - 09:15, 09:15 - 09:30, и т.д.
            - каждая карточка слота имеет статус "Занято" или "Свободно"
            - Карточки со статусом "Свободно" можно выбрать
        - Кнопки "Назад" и "Продолжить". "Назад" возвращает пользователя к выбор длительности встречи. "Продолжить" - выбирает/фиксирует дату и слот.

## Сценарии взаимодействия

### От имени гостя
1. Гость получает ссылку вида https://cal.com/ievgenii-kurennyi-tbwslh
2. При посещении видит аватар пользователя и его имя, а также 2 карточки-ссылки:
    - "Встреча 15 минут" и label "15 мин"
    - "Встреча 30 минут" и label "30 мин"
3. Гость кликает карточку "Встреча 15 минут" и попадает на страницу с URL похожим на https://cal.com/ievgenii-kurennyi-tbwslh/15min?overlayCalendar=true
4. На этой странице Гость видит трехколоночный интерфейс как в пункте 3.3
    4.1. Стрелка выбора предыдущего месяца заблокирована, если пользователь находится на странице показа текущего месяца.
    4.2. Выбрать дату в прошлом нельзя.
    4.3. Текущий день подсвечен в календаре.
    4.4. При выборе даты - обновляются временные слоты (показываются и доступные и занятые)
    4.5. Нельзя выбрать слот, который занят
    4.6. При клике на доступном слоте, поьзователь видит страницу с URL как тут https://cal.com/ievgenii-kurennyi-tbwslh/15min?overlayCalendar=true&date=2026-11-10&slot=2026-11-10T12%3A30%3A00.000Z
        4.6.1. На странице две карточки (слева направо):
            - Левая: аватар пользователя, имя пользователя, дата в формате "Tuesday, November 10, 2026" и время в формате "1:30 - 1:45pm", длительность слота "15m", "Cal Video" и часовой пояс.
            - Правая: форма с полями "Your name", "Email address", "Additional notes" и двумя кнопками: "Back" (возвращает на страницу выбора слота) и "Confirm" - сохраняет в базу данных (или localstorage - нужно решить отдельно) и показывает пользователю финальный экран (нужно придумать вид).
    4.7. При подтверждении (Confirm) регистрации пользователь видит финальный экран на странице как эта https://cal.com/booking/dPJrqDoq8DUwqww24GVpUa?flag.coep=false&isSuccessBookingPage=true&email=ikurennyi%40gmail.com&eventTypeSlug=15min
        4.7.1. На странице присутствуют:
            - Заголовок "This meeting is scheduled"
            - Подзаголовок "We sent an email with a calendar invitation with the details to everyone."
            - данные подобного типа:
                - What: 15 min meeting between Ievgenii Kurennyi and Ievgenii Kurennyi
                - When: Tuesday, November 10, 2026 \n 4:00 PM - 4:15 PM (Central European Standard Time)
                - Who: Ievgenii Kurennyi (Host) \n ikurennyi@gmail.com \n\n Ievgenii Kurennyi \n ikurennyi@gmail.com
                - Where: Cal Video
                - Additional notes: Additional note text typed by user


### От имени администратора
1. Администратор видит домашнюю страницу ("Home") на URL как этот https://app.cal.com/home
2. На домашней странице есть боковое меню со ссылками "Home", "Links", "Bookings"
3. На домашней странице есть список созданных встреч сгруппированных по дням:
    3.1. Каждый день представлен карточкой, на которой:
        - есть дата "Tue, 10 Nov"
        - есть время 4:00pm-4:15pm
        - ссылка на присоединение к звонку "Join Cal Video"
        - название встречи "15 min meeting between Ievgenii Kurennyi and Ievgenii Kurennyi"
        - список участников: "You and Ievgenii Kurennyi"
        - через какое время будет встреча: "in 4 hours and 2 minutes"
        - оставленный комментарий "Additionan notes" в виде текста. В примере это "Additional note text typed by user"
    3.2. Для каждой встрече есть кнопка "Delete booking".
4. На странице "Links" есть возмжоность отредактировать один из двух возможных слотов/интервалов: "15 min meeting" и "30 min meeting".
    4.1. У каждой из этих карточек-слотов есть тоггл "Published". То есть можно скрыть от пользователя выбор одного из интервалов.
    4.2. Каждый из интервалов имеет уникальную ссылку вида https://cal.com/ievgenii-kurennyi-tbwslh/15min или https://cal.com/ievgenii-kurennyi-tbwslh/30min которой можно поделиться с пользователем.
    4.3. Можно добавить новое событие-интервал.
    4.4. Добавление интервала или редактирование представляет из себя отдельную страницу как https://app.cal.com/links/1cFSwssaReSoEwN3B9C98x?tabName=setup, где можно:
        - изменить название "15 min meeting"
        - добавить "Description"
        - изменить URL (последняя часть где 15min или 30min)
        - изменить длительность в минутах
        - кнопка "Save"
5. Страница Bookings представляет из себя список всех событий в табличном виде с фильтрами "Upcoming", "Past"
