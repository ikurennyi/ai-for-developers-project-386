# Бронирование встреч

Сервис записи гостей на встречи с одним владельцем календаря.

## Language

**Тип встречи (Meeting type)**:
Предложение встречи с названием, описанием, длительностью и публичным адресом, по которому гость может выбрать время и создать бронирование.
_Avoid_: Тип события, вид брони, слот (в значении типа встречи).

**Бронирование (Booking)**:
Запись гостя на конкретный интервал времени с сохранёнными на момент создания данными встречи и гостя.
_Avoid_: Регистрация, тип встречи (в значении записи на конкретное время).

**Опубликованный тип встречи (Published meeting type)**:
Тип встречи, доступный гостям для выбора и создания новых бронирований.

**Скрытый тип встречи (Hidden meeting type)**:
Тип встречи, недоступный для новых бронирований, в том числе по прямой ссылке; существующие бронирования этого типа сохраняются.
